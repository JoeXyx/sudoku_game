# 数独游戏 (Sudoku Game)

一个基于 Qt 框架开发的数独游戏，支持多种难度级别和丰富的游戏功能。

## 功能特性

### 核心功能
- **数独生成器**：自动生成有效的数独谜题
- **三种难度级别**：简单 (Easy)、中等 (Medium)、困难 (Hard)
- **实时验证**：自动检查输入是否正确
- **错误提示**：高亮显示错误的单元格

### 游戏功能
- **新游戏**：选择难度开始新游戏
- **重启**：重置当前游戏到初始状态
- **清除**：清除当前选中的单元格
- **撤销/重做**：支持操作历史记录，可撤销和重做操作
- **提示**：随机填充一个空单元格的正确答案
- **自动求解**：使用回溯算法自动求解当前谜题
- **提交答案**：验证并提交最终答案
- **暂停/恢复**：暂停或恢复游戏计时器

### 界面特性
- **计时器**：实时显示游戏时间（格式：hh:mm:ss）
- **可视化反馈**：错误单元格高亮显示，提示答案以绿色显示
- **现代化 UI**：使用 Qt 样式表实现美观的界面设计

## 技术栈

- **框架**：Qt 5/6 (C++)
- **语言标准**：C++17
- **UI 设计**：Qt Designer (.ui 文件)
- **核心算法**：回溯算法（用于数独生成和求解）

## 编译和运行

### 前置要求
- Qt 5.x 或 Qt 6.x
- Qt Creator 或支持 Qt 的 IDE
- C++17 兼容的编译器

### 编译步骤

1. **使用 Qt Creator**：
   - 打开 `sudoku.pro` 文件
   - 选择构建套件（Kit）
   - 点击"构建"按钮

2. **使用命令行**：
```bash
qmake sudoku.pro
make  # 在 Windows 上使用 nmake 或 mingw32-make
```

3. **运行**：
```bash
./sudoku  # Linux/Mac
sudoku.exe  # Windows
```

## 使用说明

### 开始游戏
1. 点击"新游戏"按钮
2. 在弹出的对话框中选择难度级别（简单/中等/困难）
3. 点击"确定"开始游戏

### 游戏操作
- **输入数字**：点击单元格，输入 1-9 的数字
- **清除内容**：选中单元格后点击"清除"按钮
- **获取提示**：点击"提示"按钮，系统会随机填充一个正确答案
- **撤销操作**：点击"撤销"按钮回退上一步操作
- **重做操作**：点击"重做"按钮恢复撤销的操作
- **自动求解**：点击"求解"按钮，系统会自动完成整个数独
- **提交答案**：完成填写后点击"提交"按钮验证答案

### 游戏控制
- **暂停**：暂停游戏计时器
- **恢复**：恢复游戏计时器
- **重启**：重置游戏到初始状态，重新开始计时
- **退出**：退出游戏

## 核心算法

### 数独生成算法
1. 使用回溯算法填充完整的数独终局
2. 根据难度级别移除相应数量的数字
3. 确保生成的谜题有唯一解

### 数独求解算法
- 使用回溯算法（Backtracking）求解数独
- 递归尝试所有可能的数字组合
- 验证每个数字是否符合数独规则

## 开发说明

### 主要类说明

- **MainWindow**：主窗口类，负责游戏逻辑控制和用户交互
- **sudokuboard**：数独棋盘类，管理 9x9 的单元格网格
- **sudokucell**：数独单元格类，继承自 QLineEdit，处理单个单元格的显示和输入
- **sudokugenerator**：数独生成器类，负责生成数独谜题和求解
- **NewGame**：新游戏对话框，用于选择游戏难度

### 关键数据结构

- **Move 结构体**：记录每次操作的坐标和值变化，用于实现撤销/重做功能
- **QStack<Move>**：使用栈结构存储操作历史
